# License Activation CLI

**Язык:** Python 3

Консольный клиент для активации лицензий программных продуктов через License Activation Backend.
Поддерживает запуск из Python и в виде автономного Windows EXE.

## Возможности

- Проверка формата лицензионного ключа и контрольной суммы Luhn mod 62.
- Автоматический сбор аппаратных характеристик устройства.
- Шифрование данных с использованием AES-256-SIV.
- Отправка запроса активации на сервер.
- Отображение результата активации.
- Работа без предварительной регистрации клиента.

Вся логика проверки лицензий, формирования аппаратного отпечатка и принятия решения об активации выполняется на стороне сервера.

## Настройка

Скопируйте `config.example.toml` в `config.toml` рядом с `cli.py` или `LicenseClient.exe`.

Укажите адрес и порт сервера лицензирования.

Файл `config.toml` не включается в Git.

## Требования

Для запуска из исходного кода необходимо установить **Python 3** и добавить его в переменную окружения `PATH`.

Проверить установку Python можно командой:

```powershell
python --version
```

Для запуска автономного `LicenseClient.exe` установка Python не требуется.

## Запуск

**Из исходного кода:**

```powershell
pip install .
```

```powershell
Copy-Item config.example.toml config.toml
```

**Linux:**

```bash
cp config.example.toml config.toml
```


```powershell
python cli.py
```

**Из EXE:**

Запустите `LicenseClient.exe`, введите лицензионный ключ и дождитесь ответа сервера.

## Разработка

Установка зависимостей:

```powershell
pip install '.[dev]'
```

Запуск тестов:

```powershell
pytest
```

CI GitHub Actions выполняет проверки Ruff, mypy, pytest и сборку EXE через PyInstaller.

## Безопасность

- Лицензионный ключ не передаётся через аргументы командной строки.
- Данные устройства шифруются перед отправкой.
- Клиент не содержит встроенных секретных ключей.
- Текущая версия использует HTTP во внутренней сети без аутентификации сервера.
